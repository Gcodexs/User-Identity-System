## 📚 C# Concepts Learned

### Microsoft.Data.Sqlite

A **Microsoft-provided database connector** that allows C# applications to communicate with SQLite. It is used to execute SQL queries and store, retrieve, and modify data.

### SQLitePCLRaw.bundle_e_sqlite3

Provides the **SQLite engine** required to create and manage the database locally. It handles the underlying database operations used by the application.

### Nullable

A **C# safety feature** that helps detect potential `null` values and prevents common null-reference errors during application execution.
